# Support

Thanks for using drillr Market Dashboard.

- For setup, configuration, deployment, and product-design questions, use
  [GitHub Discussions](https://github.com/huluwa2026/drillr-market-dashboard/discussions).
- For reproducible defects, open a
  [bug report](https://github.com/huluwa2026/drillr-market-dashboard/issues/new?template=bug.yml).
- For focused improvements, open a
  [feature request](https://github.com/huluwa2026/drillr-market-dashboard/issues/new?template=feature.yml).
- For security vulnerabilities, follow the private process in
  [SECURITY.md](./SECURITY.md).

Do not post API keys, access tokens, customer data, licensed raw market-data
responses, or private deployment logs in public issues or discussions.

Questions about Drillr accounts, data entitlements, or API plans should be
directed to [Drillr](https://drillr.ai); this repository only maintains the
dashboard software.
